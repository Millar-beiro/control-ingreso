# 🏢 Control de Asistencia — Millar-beiro

Sistema web de control de asistencia para supervisores de producción.

## 🚀 Publicar en GitHub Pages

### Paso 1 — Subir archivos
1. Ve a tu repositorio: `github.com/Millar-beiro/control-ingreso`
2. Clic en **"Add file"** → **"Upload files"**
3. Sube el archivo `index.html`
4. Clic en **"Commit changes"**

### Paso 2 — Activar GitHub Pages
1. Ve a **Settings** (pestaña del repositorio)
2. En el menú izquierdo busca **"Pages"**
3. En **Branch** selecciona `main` y carpeta `/ (root)`
4. Clic en **Save**
5. Espera 1-2 minutos

### Tu página estará en:
👉 `https://millar-beiro.github.io/control-ingreso`
